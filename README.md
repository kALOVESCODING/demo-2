# ShopZone (React e-commerce)

## Run
```
npm install
npm run dev
```
Open the URL shown (usually http://localhost:5173).

## Structure
- `src/components/Layout.jsx` - shared Header + Footer on every page
- `src/data/products.js` - add or edit products here
- `src/context/CartContext.jsx` - cart state (saved in localStorage)
- `src/pages/` - Home, Products, ProductDetail, Cart
